# Benchmarks: tech-product-launch

Reference films for this theme. Each entry says what to learn from it and how its making is known: from the author's own post or source, or guessed from the picture. The review step compares a new film against the confirmed entries.

## Entry format

```markdown
### <title> — <author>
- Link:
- Made with: <stack> (source: author post / repository / guess)
- Learn: <the specific shots, type, motion or sound worth borrowing>
- Fits modes: <modes it informs>
- Status: candidate | confirmed by owner (date)
```
