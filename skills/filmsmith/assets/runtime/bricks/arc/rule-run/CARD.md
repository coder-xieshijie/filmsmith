### rule-run

- **Tells**: input as units → what is counted → one step slow → the loop → the result → an unseen case → the thesis.
- **Intent**: The viewer learns a mechanism by watching one step, then believes it from a case it never saw.
- **Fits / does not fit**: Explainers of an algorithm that runs on a tiny input in a few steps. Not: Launches; mechanisms that cannot run on a small input.
- **Slots**:

  | Role | Seconds | Repeats | Scenes that fill it | Peak | Bed kind |
  |---|---|---|---|---|---|
  | `hook` | 2–3 | 1 | chip-split | hook | intro |
  | `problem` | 3–5 | 1 | weight-histogram | – | build |
  | `demo` | 3–4.5 | 1 | merge-step | – | build |
  | `demo` | 2.5–4 | 1–3 | merge-step | – | build |
  | `proof` | 2–3 | 1 | count-to-result | – | break |
  | `climax` | 5–8 | 1 | probe-replay | reveal | drop |
  | `claim` | 3–4.5 | 1 | thesis-lines | claim | outro |

- **Length**: 22–40 s; peaks 2–3; sound bed `diagram`.
- **Example films**: the trace template's example (the trace demo film); a recomposed segment in the trace recipe.
- **Source**: own (`assets/templates/trace/content.js, timing.rules.js`), split from the template of the trace style. **Licence**: MIT (Filmsmith).
